# 為什麼要讀設計所?
我從The Sciences of the Artificial吸收後得到一個還不錯對自己的解釋 </br>
一方面是喜歡Human-computer interaction (HCI)  </br>
一方面想把學的技術應用在商業上 </br>

傳統科技 </br>
我是學好技能等著被利用的人 </br>
但我比賽過後 </br>

我發現重點還是找出你擅長領域中 </br>
剛好解決別人痛點的痛點 </br>
痛點不需要多特別 </br>
有問題那就是痛點可以持續優化 </br>
不要逃避痛點 </br>

設計 對其他人的想像諸如廣告設計 平面設計 </br>
但對於我而言 </br>
設計所更像是制定商業策略的玩家 </br>
其實從很多商業企業顧問課就能看到設計課程的蹤跡 </br>
例如 </br>
商業策略構想策略、UX策略、Pathless Path 都能看到UX的蹤跡 </br>

## 值得慶幸的是
我去年在交大應藝落榜! </br>
我以為我需要的是title  </br>
也就是校名 </br>
但我真正的需要是一個能洞察我優缺點的教授(戰師) </br>

他能抓出我的焦慮 </br>
並以後設的角度 </br>
讓我創造出更厲害的存在 </br>

## 模板

從大1到大4 </br>
我跟隨教授 </br>
想找的是他們的成功公式 </br>
也就是互動裝置你在觀看時就知道是哪個老師的作品 </br>
但我意識到我只是在模仿 </br>
而非原創 </br>
原創應該是 70%傳承30%應用 </br>

但我根本搞錯了 </br>
遇到這個教授 </br>
這半年產生了碰撞期 </br>
我根本不明白 </br>
他為甚麼對我那麼嚴格 </br>
期望這麼高 </br>
而我的心牆築的更高 </br>

我目前應當專心在蓋自己的城堡、養好自己的花園</br>
而非花更多時間去研究我要更多元的材料、種子</br>
把好奇心放在Linkography: Unfolding the Design Process的路徑上</br>

但我想我現在理解了 </br>
承認自己的不足 接受自己的專長 </br>
持續的學習 閱讀 吸收 收斂 專注 </br>
就是這樣吧! </br>
